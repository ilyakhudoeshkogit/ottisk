# История версий

У Mac- и Windows-версии с 0.6.0 общий номер версии: один релиз на GitHub — обе сборки.
Подробные списки изменений: [macos/CHANGELOG.md](macos/CHANGELOG.md) и [windows/CHANGELOG.md](windows/CHANGELOG.md).

## 0.6.1 — 20.11.2026
- Появилась сборка для Mac: универсальная (Apple Silicon и Intel), `.dmg` и `.zip`. Собирается и проверяется автоматически на GitHub.
- Код приложения не менялся.

## 0.6.0 — 17.11.2026
Первая публичная версия.
- **Окно не подвисает.** Mac: превью «Как напечатается», миниатюры, поиск белых полей, сборка PDF для печати
  и конвертация картинок идут в фоне, устаревшие пересборки отменяются, у запросов к CUPS таймауты.
  Windows: превью рисуется в отдельном STA-потоке, готовые листы и растры страниц кешируются, соседние листы рисуются заранее.
- Windows-версия перескочила с 0.3.0 на 0.6.0, чтобы номера совпадали с Mac.

## Раньше (до публикации)
- Mac 0.1–0.5 (13–15.11.2026): печать поверх CUPS, пресеты, ручная двусторонняя печать, брошюра, водяной знак,
  сканер, живое превью, пресеты ГОСТ/БГУИР/ЕСКД, очередь из нескольких документов.
- Windows 0.1–0.3 (14–17.11.2026): крупный простой интерфейс, установщик, пробный лист для двусторонней печати,
  пресет «Курсовая / ГОСТ», номера страниц, обрезка белых полей, водяной знак.
