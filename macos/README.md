# Оттиск

Простое приложение для macOS, чтобы печатать на Canon i-SENSYS MF3010 (и на любой другой принтер) без лишних окон.
Перетащил файл, нажал пресет, нажал «Печать».

Драйвер не заменяется: Оттиск работает поверх CUPS, той же системы печати, что и сама macOS.
Задания уходят через стандартные `lp`, `lpstat`, `lpoptions` и `cancel`.

> Статус: v0.6.0. Версия 0.4 собиралась на Mac (Command Line Tools, `./build-app.sh`); 0.5 и 0.6 на Mac ещё не компилировались. 106 тестов логики проходят на Linux. На MF3010 печать ещё не проверялась. История версий в [CHANGELOG.md](CHANGELOG.md).

## Что нового в v0.6

**Окно не подвисает.** Превью «Как напечатается», миниатюры, поиск белых полей, сборка PDF для печати и конвертация картинок идут в фоне; устаревшие пересборки отменяются. Запросы к CUPS ограничены таймаутом. Подробности в [CHANGELOG.md](CHANGELOG.md).

## Что нового в v0.5

**Несколько документов одной очередью.** Брось сразу несколько файлов в окно или на иконку в Dock. Слева появляется строка «Печатать все»: список документов (порядок — перетаскиванием, удалить — Delete), у каждого «Как общий пресет» или свои копии и диапазон, справа превью выбранного. «Печатать все» (⌥⌘P) отправляет их по очереди тем же кодом, что и одиночная печать (раскладка Оттиска, `print-scaling=none`). «Склеить в один PDF» — одно задание из выбранных страниц всех документов, удобно для двусторонней печати. Для ручной двусторонней очередь ждёт оборота пачки (окно оборота) и потом идёт дальше. Логика очереди — `PrintQueue` в OttiskCore с тестами.

## Что нового в v0.4

**Превью = печать.** Оттиск сам собирает итоговый PDF (N на листе, поля, масштаб, номера страниц, рамки, порядок) и показывает его в режиме «Как напечатается». Тот же файл уходит на принтер с `print-scaling=none`, поэтому что видишь, то и получаешь. «Показать поля» рисует пунктир и подписывает поля в мм.

**Пресеты «Учёба и работа»** (схема листа появляется при наведении):

| Пресет | Что делает | Основание |
|---|---|---|
| ГОСТ / курсовая | поля Л30 П15 В20 Н20 мм, номер внизу по центру, титул без номера | ГОСТ 7.32-2017, п. 6.1.1, 6.3.1–6.3.2 |
| БГУИР (СТП) | те же поля, номер внизу справа, титул без номера | СТП БГУИР 01-2024, п. 2.1.1, 2.2.8 ([PDF](https://www.bsuir.by/m/12_100229_1_185678.pdf)) |
| Рамка ЕСКД | рамка Л20 П5 В5 Н5 мм, основная надпись 185×15 (форма 2а) с номером листа | ГОСТ 2.104-2006; отступы текста — ГОСТ Р 2.105-2019, п. 5.1.3 |
| Конспект | 4 на листе, белые поля исходника срезаны | — |
| Брошюра-методичка | A5-книжечка из A4, 2 прохода | — |
| Экономия бумаги | 2 на стороне + с двух сторон | — |
| На подпись | 100 %, первая страница или твой диапазон | — |
| Слайды лекции | 4 слайда в столбик, справа линейки | — |
| Скан паспорта | реальный размер по DPI картинки, по центру | — |

Режим полей «Заменить» срезает белые края файла и ставит текст ровно в новые поля (левое поле гарантированно ≥ заданного — под дырокол). «Добавить» уменьшает всю страницу вместе с её полями.

**«Ещё»** — настройки, которые в системном диалоге спрятаны или которых нет: поле под переплёт, зеркальные поля, масштаб в %, чётные/нечётные, обратный порядок, повтор страниц, пустые листы-разделители, нумерация с N и пропуском первых, колонтитул «файл + дата», рамки вокруг страниц, порядок Z/N, обрезка белых полей, толще линии и контраст для сканов, плотность тонера (только если драйвер её даёт; у MF3010 в `lpoptions` её может не быть).

**Двусторонняя печать на MF3010.** Сначала печатаются лица (нечётные). Окно ждёт, пока задание уйдёт из очереди CUPS, и только потом включает «Стопку перевернул — печатать дальше». Схема показывает: пачка выходит сверху лицом вниз, верхом страниц к тебе → берёшь её, **не переворачивая** → поворачиваешь на столе на 180° → кладёшь в лоток подачи чистой стороной вверх, тем краем вперёд. Обороты идут в обратном порядке, при нечётном числе страниц первым идёт пустой. Механика взята из User's Guide MF3010 (бумага в лотке — стороной для печати вверх, выход лицом вниз). Не уверен в одном: каким краем драйвер подаёт верх страницы — для этого лист «Принтер → Тест двусторонней печати» и галочка «Перевернулось неправильно — повернуть оборот на 180°» (запоминается).

## Что нового в v0.2

- **Уведомление «Напечатано»**, когда задание ушло из очереди CUPS. Для ручной двусторонней печати приходит отдельное «Сторона 1 напечатана, переверни пачку». Отключается в настройках.
- **Свои пресеты.** «Сохранить как пресет…» запоминает текущие настройки (кроме диапазона страниц) под твоим названием и значком. В окне «Управлять…» пресеты можно переименовать, сменить значок, перезаписать текущими настройками, удалить и перетащить. Хранятся в `~/Library/Application Support/Ottisk/presets.json`. Если файл испорчен, он откладывается в сторону как `presets.broken-….json`, а не теряется.
- **«Печать через Оттиск» из Finder:**
  - правый клик по файлу → «Службы» → «Печать через Оттиск»;
  - Терминал: `open -a Ottisk файл.pdf`;
  - ссылка `ottisk://print?file=/путь/к/файлу.pdf&preset=economy`. Можно передать несколько `file=`, а в `preset=` указать встроенный пресет (`normal`, `economy`, `draft`, `manualDuplex`, `multiPage` или его русское название) либо имя своего.
  - Все три способа только **открывают** файл в Оттиске. Печать запускается кнопкой, чтобы случайная ссылка из браузера не могла ничего напечатать.
- **Сканер** (вкладка в боковой панели) через ImageCaptureCore: поиск сканера, разрешение (75–1200 dpi, из того, что поддерживает сканер), цвет / серый / ч/б, PDF / PNG / JPEG. Файлы сохраняются в `~/Documents/Ottisk Scans` с именами вида «Скан 2026-11-13 14-05-33.pdf», без перезаписи. Скан можно сразу отправить «В печать». Режим «Собирать сканы в один PDF» склеивает несколько сканов (например, страницы договора) в один файл. **Не проверено на MF3010**: сканер появится, только если установлен драйвер сканера Canon (ссылки ниже).
- **Брошюра.** Страницы раскладываются по две на альбомный лист A4 в порядке для сгиба: для 8 страниц лист 1 — [8 | 1] / [2 | 7], лист 2 — [6 | 3] / [4 | 5]. Если страниц не кратно 4, в конец добавляются пустые. Печать идёт в два прохода, как ручная двусторонняя. По умолчанию оборот брошюры поворачивается на 180°, потому что брошюру листают по короткому краю. Это проверяется на 4 страницах (TESTING.md, раздел 8).
- **Водяной знак** («КОПИЯ», «ЧЕРНОВИК», «ОБРАЗЕЦ» или свой текст) на каждой странице, с настройкой заметности и наклона. Рисуется через PDFKit/CoreGraphics в отдельной копии PDF, оригинал не меняется. В превью показан примерный вид.
- **Из буфера обмена** (⇧⌘V или кнопка в пустом окне): скопированные файлы, PDF, картинка, RTF или просто текст становятся документом для печати.
- **Свой пресет при запуске:** в настройках «Пресет при запуске» можно выбрать и свой пресет.
- **Английский интерфейс.** Русский остаётся основным; если в macOS выбран английский, Оттиск переключается сам. Переведены 198 строк интерфейса, названия пресетов и состояний принтера. Сообщения об ошибках, которые приходят от CUPS и macOS, остаются как есть.

## Что умеет v0.1

- **Файлы перетаскиванием.** Можно бросить в окно или на иконку в Dock, или выбрать через ⌘O.
  - PDF печатается как есть.
  - Картинки (PNG, JPEG, HEIC, TIFF и др.) вписываются в лист A4 с полями, ориентация подбирается сама.
  - Текст (`.txt`, `.md`, код) превращается в PDF средствами macOS.
  - Документы `.docx`, `.doc`, `.odt`, `.rtf` и `.html` открываются через системный `NSAttributedString` и сохраняются в PDF.
  - У Word-файлов со сложной вёрсткой (колонтитулы, сноски, плавающие картинки) вид может отличаться от Word. Для точной печати лучше сохранить такой файл в PDF.
  - Pages и Keynote пока не поддерживаются: экспортируй их в PDF.
- **Превью** на PDFKit с миниатюрами. Страницы, которые не попали в диапазон, выглядят бледными.
- **Принтеры из CUPS** с состоянием:
  - «Готов», «Печатает», «Нет бумаги», «Замялась бумага», «Открыта крышка», «Мало тонера», «Приостановлен», «Не подключён» (если CUPS это сообщает).
  - Для приостановленной очереди есть кнопка «Возобновить».
- **Пресеты одной кнопкой:**
  - **Обычно**: по размеру листа.
  - **Экономия тонера**: включает опцию экономии, если драйвер её даёт. Оттиск сам ищет такую опцию в `lpoptions -l` (`TonerSave`, `EconoMode`, `CNTonerSaving` и похожие). Если драйвер её не даёт, переключатель неактивен, и об этом честно написано.
  - **Черновик**: `print-quality=3` (draft), самое низкое разрешение, если у драйвера есть выбор, экономия тонера и 2 страницы на листе.
  - **С двух сторон**: ручная двусторонняя печать (подробнее ниже).
  - **2 на листе**.
- **Свои настройки:**
  - копии;
  - диапазон страниц («1-3, 5, 8-»), с понятными ошибками;
  - 1, 2, 4, 6, 9 или 16 страниц на листе;
  - ориентация и размер бумаги (из драйвера);
  - вписать в лист;
  - обратный порядок.
- **Ручная двусторонняя печать.** У MF3010 нет дуплекса, поэтому печать идёт в два прохода:
  1. Оттиск сам собирает PDF с лицевыми сторонами: 1, 3, 5…, а при «N на листе» группы по N.
  2. Показывает, как положить пачку обратно в лоток.
  3. Печатает оборотные стороны в обратном порядке.

  Подробности:
  - Если страниц нечётное число, Оттиск добавляет пустой оборот, чтобы ничего не съехало.
  - Копии раскладываются правильно: каждая копия начинается с нового листа.
  - В меню «Принтер → Тест двусторонней печати» печатается лист «1 / 2» со стрелками «ВЕРХ», чтобы один раз понять, как класть бумагу.
  - В настройках есть «Поворачивать оборот на 180°».
- **Очередь заданий** с отменой одного задания или всех. Счётчик заданий виден на иконке в Dock.
- **Значок в строке меню**: состояние принтера, очередь, отмена и «Открыть Оттиск». Если закрыть окно, приложение остаётся в строке меню.
- **История** последних печатей: повторить или показать файл в Finder. Внизу сайдбара показано, сколько страниц отправлено в CUPS. Это не подтверждение физической печати: отменённые и не дошедшие до бумаги задания тоже входят в счётчик.
- **Основная надпись в духе ЕСКД** внизу панели: документ, страницы, копии, листы, принтер, пресет.
- **Команда `lp`**, которая уйдёт в CUPS, видна в «Команда lp». Удобно для отладки и для портфолио.
- Светлая и тёмная тема следуют за системой.

## Сборка и запуск

Нужно:
- macOS 14 Sonoma или новее;
- Command Line Tools: `xcode-select --install`. **Xcode не нужен**: с версии 0.3.1 Оттиск проверенно собирается одними Command Line Tools (macOS SDK 27.2, Swift 6.4, MacBook Air M-серии).

```bash
cd ottisk/macos
./build-app.sh --open        # соберёт dist/Ottisk.app и запустит
# или
./build-app.sh --install     # соберёт и положит в ~/Applications/Ottisk.app
```

Что делает скрипт:
1. `swift build -c release`.
2. Собирает бандл `dist/Ottisk.app`: Info.plist и иконку (через `sips` и `iconutil`).
3. Подписывает ad-hoc (`codesign --sign -`), Apple ID не нужен.

Собирается под архитектуру твоего Mac (Apple Silicon или Intel).

### Если macOS не даёт открыть

Приложение не нотариально заверено. Если ты собрал его сам на своём Mac, оно обычно открывается сразу: у собранных локально файлов нет «карантина».
Если пришёл уже готовый `.app` (скачан или передан):
- **macOS 15 и новее:** попробуй открыть, затем зайди в «Системные настройки → Конфиденциальность и безопасность» и внизу нажми «Всё равно открыть».
- **macOS 14:** правый клик по приложению → «Открыть» → «Открыть».
- Или в Терминале: `xattr -dr com.apple.quarantine ~/Applications/Ottisk.app`.

### Тесты логики

```bash
swift test
```

Тесты покрывают разбор вывода `lpstat` и `lpoptions`, диапазоны страниц, аргументы `lp`, пресеты (встроенные и свои, JSON), план двусторонней печати, раскладку брошюры, размер водяного знака, ссылки `ottisk://`, отслеживание завершённых заданий, параметры скана и историю.

На Linux (без Mac) всё, что можно проверить, проверяет `./scripts/check-linux.sh`: тесты, синтаксис файлов приложения, Info.plist и полноту перевода.
Если `swift test` ругается на отсутствие XCTest, значит, для тестов на Mac нужен полный Xcode. Само приложение собирается и без него.

## Если CUPS не видит MF3010

1. Подключи принтер по USB и включи его.
2. Открой «Системные настройки → Принтеры и сканеры → Добавить принтер» и выбери Canon MF3010.
3. Если macOS не нашла драйвер или печать не идёт, поставь официальный драйвер Canon для Mac. Для MF3010 Canon выпускает его под названием **MF Printer Driver & Utilities for Mac**:
   - Страница поддержки i-SENSYS MF3010 (Canon Europe): https://www.canon-europe.com/support/consumer/products/printers/i-sensys/mf-series/i-sensys-mf3010.html
   - Страница драйвера V10.11.14 для macOS 11.7.11 – macOS 27.0.1, файл `mac-mf-v101114-00.dmg`, MF3010 в списке моделей: https://my.canon/en/support/0101318901?model=imageCLASS+MF3010
   - Полный список драйверов модели (imageCLASS MF3010 — это та же модель для рынка Австралии и Азии): https://www.canon.com.au/laser-printers/imageclass-mf3010/support
   - Сканер ставится отдельно: «Scanner Driver & Utilities for Mac V2.15.22», он есть в тех же списках.
4. После установки удали старую очередь, добавь принтер заново и выбери драйвер Canon.
5. В Оттиске нажми ⌘R (обновить) или «Принтер → Обновить состояние».

Если что-то не так, запусти `./scripts/diagnose-printer.sh`. Скрипт ничего не меняет, а только собирает вывод `lpstat` и `lpoptions` в `ottisk-diagnose.txt` (серийный номер маскируется). По этому файлу можно точно подогнать «Экономию тонера» под твой драйвер.

## Shortcuts и App Intents

App Intents (действия Оттиска прямо в приложении «Команды») **в v0.2 нет**, и это осознанно. Чтобы macOS увидела интенты, при сборке нужен шаг извлечения метаданных (`appintentsmetadataprocessor`), а его запускает только система сборки Xcode. Обычный `swift build` из Command Line Tools его не делает: код бы собрался, но в «Командах» ничего бы не появилось.

Что работает уже сейчас:
- действие «Открыть URL-адреса» со ссылкой `ottisk://print?file=…&preset=draft`;
- действие «Запустить shell-скрипт»: `open -a Ottisk "$@"` (передать файлы на вход);
- Quick Action в Automator с тем же shell-скриптом. Он появится в правом клике Finder рядом со службой.

Настоящие App Intents будут, когда появится Xcode-проект (вместе с виджетом).
