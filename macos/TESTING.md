# Первая проверка на Mac

Это исходники, не проверенный macOS-релиз (v0.2.0). На Linux успешно прошли 54 теста,
парсинг всех Swift-файлов, проверка Info.plist и полноты перевода (`./scripts/check-linux.sh`).
Нужна сборка с SDK macOS. Разделы 1–5 — из v0.1, разделы 6–11 — новое в v0.2.

## 1. Сборка

- macOS 14+; `xcode-select --install` при отсутствии инструментов.
- `./build-app.sh --install --open`.
- Если ошибка: сохранить весь вывод команды; ничего не устанавливать из случайных источников.
- Проверить, что окно и меню-бар открываются, ⌘Q завершает приложение.
- Сменить светлую/тёмную тему; сузить окно до минимального размера.

## 2. Файлы и превью (без расхода бумаги)

- PDF 6 страниц; миниатюры, переходы кликом/прокруткой.
- Диапазон `2-3,5` → три страницы выделены, штамп показывает 3.
- Ошибочные диапазоны `0`, `9`, `4-2` → печать недоступна.
- JPEG и PNG (горизонтальные/вертикальные), UTF-8 TXT > 2 страниц.
- DOCX с простым текстом → сверить PDF-превью. Сложный Word — экспорт в PDF отдельно.
- Перетащить один/несколько файлов на окно и на иконку в Dock; ⌘O.
- Удалить документ из списка: оригинал должен остаться нетронутым.

## 3. Принтер и очередь

- `./scripts/diagnose-printer.sh` → локальный отчёт. В отчёте есть имена очередей,
  пользователей и устройства; перед передачей просмотреть/убрать личное.
- Имя MF3010 появляется в списке; проверить состояние без USB/с USB.
- Печать одного тестового листа, отмена задания в очереди, ⌘R.
- CUPS «Готов» значит готовность очереди; не гарантия, что USB физически подключён.
  Драйвер может обновить состояние только после отправки задания.
- Экономия: есть ли реальная опция в `lpoptions -l`? Если нет — не обещать эффект.
- Напечатать 2 копии по 2 страницы; диапазон `2-3` + 2 на листе (должны быть страницы 2 и 3).

## 4. Ручная двусторонняя (начать с одной копии)

- Меню «Принтер → Тест двусторонней печати» (ровно 1 лист, две стороны).
- Дождаться физического выхода бумаги; исчезновение из очереди ещё не гарантирует выход.
- Проверить ориентацию. При необходимости поменять «Поворачивать оборот на 180°», повторить тест.
- 6 страниц: лица 1,3,5; обороты 6,4,2. При неверном порядке — изменить настройку
  «Вторую сторону печатать с последнего листа» и записать реальную схему загрузки MF3010.
- 5 страниц: лица 1,3,5; обороты пустая,4,2. Проверить, не пропускает ли драйвер чистые листы.
- 2 копии документа 3 страницы; на каждой паре должны быть 1/2 и 3/пусто.
- N=2, документ 5 страниц: две стороны первого листа [1,2]/[3,4], второй [5,пусто]/[пусто,пусто].
- Отмена второй стороны не отменяет уже отправленное задание первой стороны — отменять в очереди.

## 5. Данные

- История сохраняется после перезапуска; «Ещё раз» только открывает исходный файл, не печатает без проверки.
- Удалённый/перемещённый исходник → понятная ошибка.
- История — список отправленных заданий, а не подтверждение успешной печати.
- Закрытие окна → значок в строке меню остаётся; «Открыть Оттиск» возвращает окно.

## 6. Уведомления

- При первом запуске macOS спросит разрешение на уведомления → «Разрешить».
- Напечатать 1 лист → через несколько секунд после выхода бумаги баннер «Напечатано: имя файла».
- Отменить задание кнопкой в Оттиске → уведомления нет.
- Ручная двусторонняя: после первой стороны баннер «Сторона 1 напечатана».
- Настройки → «Уведомлять, когда задание напечатано» выкл. → баннеров нет.
- Известное ограничение: задание, отменённое не из Оттиска (системной очередью), тоже даст «Напечатано».

## 7. Свои пресеты

- Выставить 2 копии + 4 на листе → «Сохранить как пресет…» → «Конспекты» → кнопка появилась и подсвечена.
- Попробовать сохранить «черновик» или пустое название → понятная ошибка под полем.
- Сменить настройки → подсветка пропала; нажать «Конспекты» → настройки вернулись, диапазон страниц остался свой.
- «Управлять…»: переименовать (Enter), сменить значок, «Обновить», перетащить, удалить.
- Перезапустить приложение → пресеты на месте (`~/Library/Application Support/Ottisk/presets.json`).

## 8. Брошюра (сначала 4 страницы = 1 лист)

- PDF на 4 страницы → «Брошюра» → подсказка «Лист 1: [4 | 1] / [2 | 3]».
- Печать → лист с 4 и 1 → переложить как для обычной двусторонней → «Печатать сторону 2».
- Сложить лист пополам: страницы должны идти 1, 2, 3, 4 и стоять головой вверх.
- Если оборот вверх ногами — выключить «Поворачивать оборот брошюры на 180°» и повторить.
- Потом 8 страниц (2 листа): вложить листы друг в друга, порядок 1…8. 5 страниц → в конце пустые.

## 9. Водяной знак

- Выбрать «КОПИЯ» из меню рядом с полем → в превью полупрозрачная надпись.
- Напечатать 1 страницу (или отменить задание и открыть PDF из `$TMPDIR/Ottisk/watermark-*.pdf` в Просмотре):
  надпись по диагонали, текст документа виден, исходный файл не изменился.
- Повёрнутая (альбомная) страница PDF → знак по центру, страница не обрезана.
- Знак + 2 на листе / + брошюра → знак на каждой исходной странице.

## 10. Finder, Терминал, ссылки

- После `./build-app.sh --install`: правый клик по PDF в Finder → «Службы» → «Печать через Оттиск».
  Если пункта нет — выйти из системы и зайти снова или включить его в
  «Системные настройки → Клавиатура → Сочетания клавиш → Службы → Файлы и папки».
- `open -a Ottisk ~/Desktop/test.pdf` → файл в списке.
- `open "ottisk://print?file=$HOME/Desktop/test.pdf&preset=draft"` → файл открыт, выбран «Черновик», ничего не напечатано само.
- Ссылка на несуществующий файл → понятная ошибка.

## 11. Сканер (не проверено на MF3010)

- Нужен «Scanner Driver & Utilities for Mac» от Canon (README). Без него вкладка честно пишет, что сканер не найден.
- Вкладка «Сканер» → устройство появилось, «Готов к сканированию».
- 300 dpi, серый, PDF → «Сканировать» → файл в `~/Documents/Ottisk Scans`, имя «Скан …».
- PNG / цвет / 600 dpi; второй скан подряд не перезаписывает первый.
- «В печать» добавляет скан в список документов.
- «Собирать сканы в один PDF» → 2–3 скана → «Страниц в документе: 3» → «Сохранить PDF» → один файл на 3 страницы.
- Если ImageCaptureCore сканер не видит, а «Захват изображений» видит — прислать скриншот, это баг Оттиска.

## Буфер обмена и пресет при запуске

- Скопировать абзац текста → ⇧⌘V → документ «Буфер обмена …txt» с превью.
- Скопировать картинку (⌃⌘⇧4 → снимок в буфер) → ⇧⌘V → картинка вписана в A4.
- Скопировать файл в Finder (⌘C) → ⇧⌘V → открыт сам файл.
- Пустой буфер → понятная ошибка.
- Настройки → «Пресет при запуске» → свой пресет → перезапуск → он подсвечен.

## Двусторонняя печать после перезапуска (0.3)

- Включи «Двусторонняя (вручную)», документ на 3–4 страницы → «Печать» → дождись окна «Сторона 1 отправлена».
- Закрой Оттиск через ⌘Q, не нажимая кнопок → открой снова → окно «Незавершённая двусторонняя печать» со временем отправки.
- «Печатать сторону 2» → оборот печатается, при следующем запуске окно больше не появляется.
- Повтори и нажми «Отменить вторую сторону» → после перезапуска окна нет, папка `~/Library/Application Support/Ottisk/Pending` пустая.
- Выключи принтер, перезапусти Оттиск с незавершённым заданием → в окне предупреждение, что принтера нет в списке.

## Английский язык

## v0.4: превью, пресеты, «Ещё», двусторонняя

Без бумаги:
- Открыть PDF курсовой. «Как напечатается» → пресет «ГОСТ / курсовая»: пунктир 30/15/20/20, на 1-й странице нет номера, на 2-й — «2» внизу по центру. Покрутить поля — превью обновляется примерно через четверть секунды.
- «Конспект», «Слайды лекции», «Экономия бумаги»: миниатюры показывают «лицо/оборот», число листов в штампе совпадает.
- «Ещё»: каждый пункт меняет превью (кроме плотности тонера — её нет в превью).
- Наведение на пресет показывает схему листа.
- Свой пресет из ГОСТ с переплётом 10 мм → перезапуск → настройки на месте.

На бумаге (1–2 листа на проверку):
- ГОСТ: линейкой — левое поле ≥ 30 мм (принтер может сдвигать на ~1 мм), номер по центру ≈ 10 мм от низа.
- Рамка ЕСКД: рамка 20/5/5/5 мм, штамп 185×15 мм в правом нижнем углу.
- «Скан паспорта» на картинке с DPI: размер совпадает с оригиналом.
- Двусторонняя: «Принтер → Тест двусторонней печати». Кнопка «Стопку перевернул — печатать дальше» серая, пока задание в очереди. Положить пачку как на анимации. Если «2» вверх ногами — включить «Перевернулось неправильно…» и повторить, запомнить.
- 5 страниц «С двух сторон»: лица 1,3,5; первым идёт пустой оборот, затем 4 и 2 — на листе с 5 оборот пустой.
- Если в CUPS задания уходят слишком рано (до выхода последнего листа) — записать, это ограничение CUPS.

## v0.5: несколько документов одной очередью

Без бумаги:
- Выбрать сразу 3 файла (PDF, картинка, TXT) через ⌘O или перетащить на окно и на иконку в Dock → в списке три документа, появилась строка «Печатать все (3)».
- Перетащить документ в списке на другое место → порядок поменялся; в «Печатать все» тот же порядок.
- Delete на выбранном документе убирает его из списка; файл в Finder на месте.
- «Печатать все» → у документа «Свои копии и страницы» → копии 2, диапазон `9999` → красная ошибка, этот документ будет пропущен.
- Выбор документа справа показывает его превью.

На бумаге (3–4 листа):
- Три коротких документа (1–2 страницы), общий пресет «Чёрновик»/обычный → «Печатать все»: документы выходят по порядку списка, статусы по очереди становятся «Отправлено», тост «Очередь напечатана».
- У второго документа «Свои копии» = 2 → вышло две копии именно его. Диапазон `2` на PDF из 3 страниц → только вторая.
- «Склеить в один PDF» → одно задание «Склеено: N страниц» в «Очереди» (не три); порядок страниц как в списке.
- Двусторонняя: пресет «С двух сторон» + два документа по 2 страницы → печатается лицо первого, открывается окно оборота, очередь НЕ шлёт второй документ. Перевернуть, «Печатать дальше» → оборот, затем второй документ (новое окно оборота). «Отменить вторую сторону» → остальные пропущены.
- Склейка + двусторонняя: один проход лиц, один оборот на все документы.
- «Остановить» во время очереди → не начатые документы «Пропущен».
- Во время очереди панель настроек справа недоступна, список нельзя переставлять.
