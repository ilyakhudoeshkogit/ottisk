# История изменений — Оттиск для Windows

## 0.6.0 — 17.11.2026
Первая публичная версия в репозитории. С неё у Windows- и Mac-версии общий номер версии (после 0.3.0 сразу 0.6.0,
чтобы один релиз на GitHub содержал обе сборки одной версии). Чтобы окно не подвисало:
- **Превью рисуется в отдельном STA-потоке** (`StaWorker`): WPF-рисованию нужен STA, а в главном потоке оно подвешивало бы окно. Растр страниц PDF готовится заранее в пуле потоков (`SideRenderer.Prewarm`).
- **Устаревшее превью отменяется**: если настройки поменялись, недорисованный лист бросается.
- **Кеш готовых листов**: «Назад/Вперёд» по уже показанным листам — мгновенно; соседние листы рисуются заранее.
- **Кеш растров страниц PDF** (последние 32): включение номеров, водяного знака или ч/б не рендерит PDF заново.
- **Большие фото** для превью один раз уменьшаются и запоминаются; на печать по-прежнему идёт оригинал.
- Поиск принтеров: если Windows отвечает дольше 10 с, окно показывает «подождите», а не молчит.
- Пауза перед пересчётом превью 200 мс (была 120), чтобы не пересчитывать на каждую набранную цифру.

Не проверено на настоящей Windows и с принтером: собирается кросс-сборкой, 131 тест логики проходит.


## 0.3.0 — 17.11.2026
- **Номера страниц** («Дополнительно» → «Номера страниц (внизу по центру)»): арабские цифры, 12 пт, внизу по центру области
  печати посередине нижнего поля (как на Mac); «Начать с N» (кнопки − / +) и «Без номера на первой странице (титул)».
  Номер привязан к странице документа — при перепечатке одной страницы номер тот же. При нескольких страницах на листе
  и в брошюре — мелкий номер (7 пт) под каждой страницей, ячейка ужимается на 4,5 мм.
- Пресет **«Курсовая / ГОСТ»** включает нумерацию: титул считается, но без номера (ГОСТ 7.32-2017, п. 6.3.1–6.3.2, сверено
  с Mac-версией); при переходе на другой пресет нумерация выключается.
- **«Обрезать белые поля исходника»**: снимок страницы → bounding box непустых пикселей (порог 235, строка/столбец считается,
  если в нём ≥ 2 тёмных пикселей, запас 1 мм) → общая рамка для страниц одного размера; печатается только непустая часть.
  В пресете ГОСТ содержимое прижимается к полям и не увеличивается больше, чем в файле (кегль как в оригинале).
- **Водяной знак**: «ЧЕРНОВИК» / «КОПИЯ» / «ОБРАЗЕЦ» или своё слово, по диагонали 45°, светло-серый, полупрозрачный,
  кегль подбирается по размеру страницы (12–160 пт, как на Mac), на каждой странице документа.
- Всё рисуется одним кодом (`SideRenderer`) в живом превью и при печати, в том числе на перевёрнутых оборотах.
- Настройки: запоминаются «начать с», «титул без номера» и последнее слово водяного знака; файл настроек 0.2.0 читается.
- Ottisk.Core: `PageNumbering`, `PageLabel`, `Watermark`/`WatermarkMark`, `ContentBounds`, `Placement.Source`,
  `SideLayout.Labels`/`Watermarks`, `LayoutPlanner.Decorate`. Тестов: 95 → 131.

## 0.2.0 — 16.11.2026
- **Пробный лист для двусторонней печати** («Дополнительно» → «Двусторонняя печать: пробный лист и настройки»):
  1 лист — лицо с крупной стрелкой «ВЕРХ» и «1», окно оборота, затем оборот с «2». Потом вопрос «Как вышло?»
  (всё ровно / «2» вверх ногами / «2» на той же стороне) — Оттиск сам ставит галочки «Оборот выходит вверх ногами» /
  «Принтер выкладывает листы лицом вверх» и запоминает их в `%APPDATA%\Ottisk\settings.json`.
- Окно оборота подстраивается под «лицом вверх»: просит перевернуть стопку, а не поворачивать её.
- **Пресет «Курсовая / ГОСТ (поле под дырокол)»**: поля ГОСТ 7.32-2017 — левое 30, правое 15, верх и низ 20 мм
  (как в Mac-версии); страница целиком уменьшается с сохранением пропорций и прижимается к левому верхнему углу полей.
  В превью — пунктир полей и отметки отверстий дырокола (на печать не идут). Галочка «+20 мм» в этом пресете не нужна и выключается.
- **Размер бумаги**: A4 (по умолчанию), A5, Letter — в списке только то, что умеет принтер (если драйвер не сообщает — все три).
  Выбор запоминается; в билет печати передаётся нужный носитель.
- Ottisk.Core: `Papers`, `PageMargins`, `DuplexCalibration`, `UserSettings` (формат файла настроек; старый файл 0.1.0 читается).
  Тестов: 45 → 95.
- Версия берётся из файла `VERSION` (build.sh, установщик).

## 0.1.0 — 14.11.2026
- Первая версия: крупный русский интерфейс, PDF и фото, пресеты (обычная, экономия 2 на листе, ручная двусторонняя,
  брошюра, чёт/нечёт), копии, диапазон, ч/б, поле под дырокол, живое превью, установщик NSIS без прав администратора.
